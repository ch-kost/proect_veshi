# Система учета истории владения предметами

Консольное приложение хранит предметы, владельцев и все периоды владения.
Версия ПР3 продолжает ПР2 и переводит предметную область на объектную модель,
не меняя совместимый JSON-формат данных.

## Возможности

- просмотр, поиск, добавление и сортировка предметов;
- просмотр владельцев и полной истории владения;
- передача предмета существующему или новому владельцу;
- отмена последней передачи;
- расчет длительности завершенных периодов;
- статистика и автоматическое сохранение в JSON.

Дата вводится как `ДД.ММ.ГГГГ`, например `14.09.2026`. Также принимается
формат `ГГГГ-ММ-ДД`, который используется в JSON-файлах.

## Объектная модель

- `Entity` — базовый класс сущностей с положительным идентификатором;
- `Item(Entity)` — предмет, содержащий историю и операции передачи;
- `Owner(Entity)` — владелец предметов;
- `OwnershipPeriod(Entity)` — связь предмета и владельца на интервале дат.

`Item` и `Owner` демонстрируют наследование от общей сущности. Их разные
реализации `__str__()` полиморфно используются при выводе. Закрытие и повторное
открытие периода выполняются методами, поэтому некорректное состояние нельзя
создать прямым изменением даты. Объект `OwnershipPeriod` связывает конкретные
объекты `Item` и `Owner`, что демонстрирует композицию и взаимодействие.

## Структура

```text
proekt/
├── main.py                  # меню и пользовательские сценарии
├── models/                  # Entity, Item, Owner, OwnershipPeriod
├── services.py              # функции обработки коллекций объектов
├── storage.py               # преобразование объектов в JSON и обратно
├── utils.py                 # безопасный ввод дат и чисел
├── data/                    # предметы, владельцы и периоды владения
├── tests/                   # автоматические тесты pytest
└── requirements.txt         # pytest и flake8
```

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Тестирование и качество кода

```powershell
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m flake8 . --exclude=.venv
```

Тесты проверяют создание и взаимодействие объектов, наследование,
полиморфный вывод, передачу и отмену, обработку ошибок, функции коллекций и
полный цикл сохранения/загрузки JSON с восстановлением ссылок между объектами.
