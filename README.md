# Система учета истории владения предметами

Учебный консольный проект хранит предметы, владельцев и все периоды владения.
Версия ПР2 развивает сценарий ПР1 с помощью коллекций, функций, циклов,
модулей, обработки исключений, JSON-файлов и автоматических тестов.

## Возможности

- просмотр и поиск предметов;
- добавление и сортировка предметов;
- просмотр полной истории владения;
- передача предмета существующему или новому владельцу;
- отмена последней передачи;
- статистика по данным проекта;
- автоматическая загрузка и сохранение JSON.

Дата в консоли вводится как `ДД.ММ.ГГГГ`, например `14.09.2026`.
Также поддерживается формат `ГГГГ-ММ-ДД`, используемый внутри JSON.

## Структура

```text
proekt/
├── main.py                  # меню и сценарии взаимодействия
├── items.py                 # коллекция предметов, поиск и сортировка
├── owners.py                # коллекция владельцев
├── ownership.py             # передачи, отмена и статистика
├── storage.py               # чтение и запись JSON
├── utils.py                 # безопасный ввод чисел и дат
├── data/                    # предметы, владельцы и периоды владения
├── tests/                   # автоматические тесты pytest
└── requirements.txt         # pytest и flake8
```

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

При первом просмотре доступны демонстрационные данные. Команда `0` сохраняет
изменения и завершает программу. Изменения после передачи или её отмены также
сохраняются сразу.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m flake8 . --exclude=.venv
```

Тесты проверяют добавление, поиск и сортировку, успешную передачу, запрет
некорректных передач, отмену, длительность периода и JSON-хранилище.

## Развитие проекта

- ПР1: один предмет и одна передача в переменных программы;
- ПР2: коллекции, модули, циклическое меню, JSON и тесты;
- ПР3: классы `Item`, `Owner`, `OwnershipPeriod` и взаимодействие объектов.
