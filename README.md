# Система учета истории владения предметами

## Назначение

Приложение предназначено для учета принадлежности предметов, периодов владения и передачи вещей между владельцами.

## Целевая аудитория

Коллекционеры, семьи и небольшие сообщества, которым нужно знать, кому принадлежит предмет и когда он был передан.

## Предметная область

У предмета есть текущий владелец и дата начала владения. При передаче завершается период прежнего владельца и начинается период нового. В дальнейшем приложение будет хранить всю последовательность передач каждого предмета.

## Основные сущности

- Предмет: название и описание вещи.
- Владелец: человек, которому принадлежит предмет.
- Период: даты начала и окончания владения предметом.
- Передача: смена владельца предмета в определенную дату.

## Основные функции

В начальной версии реализованы:

1. Просмотр карточки предмета, текущего владельца и даты начала владения — `show_item()`.
2. Расчет продолжительности владения в днях — `ownership_days()`.
3. Проверка возможности передачи другому владельцу — `can_transfer()`.
4. Передача предмета с выводом завершенного периода и обновленной карточки — `main()`.

Передача запрещена, если имя нового владельца пустое, совпадает с текущим без учета регистра и крайних пробелов, дата раньше начала владения или позже сегодняшнего дня. Неправильный ввод даты обрабатывается сообщением об ошибке.

Начальная версия работает с одним демонстрационным предметом — фотоаппаратом «Зенит-Е». Его начальный владелец — Анна Иванова, дата приобретения — 10.01.2026. За запуск можно выполнить одну передачу. Данные хранятся в переменных и после завершения программы не сохраняются. Имена пока заменяют идентификаторы владельцев.

Период рассчитывается как разность дат без включения дня передачи в завершенный период. Передача в день приобретения допустима и дает 0 дней.

## Запуск

Требуется Python 3.10 или новее. Сторонние библиотеки не нужны.
Откройте терминал в папке проекта:

```powershell
python main.py
```

Для создания виртуального окружения и запуска в нем:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe main.py
```

Папка `.venv` создается локально и исключена из Git.

Пример ввода по порядку: `1`, `Борис Петров`, `2026`, `9`, `14`.
При дате компьютера не раньше 14.09.2026 программа передаст предмет Борису и выведет длительность завершенного владения Анны — 247 дней. Введите `0`, чтобы выйти без передачи.

## Используемые конструкции Python

Строки, целые числа, логические значения, арифметические операции, сравнения, ветвления `if`, преобразование `int()`, функции и импорт `date` из стандартного модуля `datetime`. Для безопасного ввода даты добавлен небольшой блок `try/except`. Коллекций, циклов и собственных классов в программе нет.

## Проверка и отладка

Проверены успешная передача, отмена, неизвестная команда, пустое имя, повторный владелец, дата до приобретения, будущая дата, нечисловой ввод и несуществующая календарная дата. Проверены нулевая длительность, високосный февраль и запрет обратного периода.

Для демонстрации отладки в IDE:

1. Установите breakpoint на строке `period_days = ownership_days(acquired_on, transfer_on)`.
2. Запустите отладку и введите данные примера выше.
3. Проверьте значения `current_owner`, `new_owner`, `transfer_on` и `is_allowed`.
4. Выполните расчет пошагово: `period_days` должен стать равен 247.
5. Для учебной ошибки временно поменяйте порядок вычитания дат в `ownership_days()`. Получится −247. В отладчике определите причину и восстановите правильный порядок.

Личная демонстрация отладки в IDE, прохождение Яндекс Практикума и согласование темы с преподавателем должны быть выполнены отдельно; здесь они не отмечены как завершенные.
