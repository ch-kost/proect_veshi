# План веб-интерфейса ПР5

Индивидуальный проект: система учета истории владения предметами.
Исходная версия ПР3: `ad56dea`. Перед доработкой проходят 13 тестов pytest,
flake8 не обнаруживает замечаний. Консольный код и JSON-хранилище сохраняются.

## Страницы

| Адрес | Назначение | Django-приложение |
| --- | --- | --- |
| `/` | Описание проекта, статистика и навигация | homepage |
| `/items/` | Список и поиск предметов | catalogue |
| `/items/<id>/` | Предмет, текущий владелец и история | catalogue |
| `/owners/` | Список владельцев | owners |
| `/owners/<id>/` | Владелец и связанные предметы/периоды | owners |
| `/history/` | Все периоды владения | history |
| `/history/<id>/` | Один период и связанные объекты | history |

Django-проект называется `ownership_site`. На этапе ПР5 страницы формируются
через `HttpResponse` и общую функцию `page()`. На ПР6 разметка будет перенесена
в шаблоны, а общая функция заменена на `base.html` и `render()`.

Веб-страницы только читают существующие данные. Добавление и передача вещей
продолжают работать в консоли. Несуществующие объекты возвращают HTTP 404.
Собственный обработчик неизвестного адреса проверяется при `DEBUG=False`.
