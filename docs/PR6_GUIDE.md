# Демонстрация ПР6

1. В терминале проекта выполнить `python manage.py check`,
   `python -m pytest -v` и `python -m flake8 .` с выбранным `.venv`.
2. Запустить `python manage.py runserver` и открыть `http://127.0.0.1:8000/`.
3. Через меню открыть предметы, выбрать фотоаппарат, перейти из истории
   к одному периоду и затем к его владельцу. Показать связь трёх сущностей.
4. Открыть `templates/base.html`: общая структура и блоки title/content.
5. Открыть `catalogue/item_list.html`: extends, for/empty, include и length.
6. Открыть `catalogue/views.py`: получение данных, словарь context, render.
7. Открыть `catalogue/urls.py` и карточку: app_name, name и тег url.
8. Показать фильтр date в истории и default в карточке без описания.
9. Открыть `homepage/static/homepage/`: CSS, JS, SVG. В браузере видны
   логотип, оформление и год в подвале.
10. Показать отсутствие объекта `/items/9999/` (HTTP404). Для собственной
    страницы404 отключить DEBUG на время проверки согласно README.
11. Показать в Git отдельные PR5 и PR6 коммиты. В PR5 HTML был внутри
    Python и page(), в PR6 — отдельные HTML-шаблоны и render().

Данные предметной области всё ещё в JSON, классы — в models/.
Django ORM, формы и авторизация предметной области относятся к следующим
работам. Изменять предметы и владельцев можно прежним консольным меню.
